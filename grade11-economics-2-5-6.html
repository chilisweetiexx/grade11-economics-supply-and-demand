經濟學 2-5～2-6 市場均衡・供需雙重變動・政府管制 重點筆記

價格機能（看不見的手）、供需變動與均衡點推移、價格上限 vs 價格下限精華歸納

1. 市場均衡與價格機能（看不見的手）

(1) 均衡條件

在自由競爭市場中，當消費者願意購買的需求量與生產者願意供給的數量相等時，即達成市場均衡，決定均衡價格（$P^*$）與均衡交易量（$Q^*$）[cite: 5, 6]：

$$Q_d = Q_s \implies P = P^*, \quad Q = Q^*$$

(2) 市場失衡與自律調整機制

市場狀態 供需數量關係 市況特徵 價格自律調整方向
超額供給（供過於求） $Q_s > Q_d$（此時市價高於均衡價：$P > P^*$）[cite: 5, 6] 商品滯銷、存貨積壓賣不出去[cite: 5] 廠商為出清存貨降價競爭 $\implies$ 價格下跌（$P \downarrow$）[cite: 5]
超額需求（供不應求 / 短缺） $Q_d > Q_s$（此時市價低於均衡價：$P < P^*$）[cite: 5, 6] 買方搶購、排隊排不到、商品短缺[cite: 5, 6] 消費者加價搶購 $\implies$ 價格上漲（$P \uparrow$）[cite: 5]

這種透過買賣雙方自發競爭使市況自動回歸均衡點的力量，稱為價格機能（Price Mechanism）或市場機能[cite: 5]。

2. 供需變動對市場均衡（$P^*$ 與 $Q^*$）的影響法則

(1) 單一力量變動的 4 大基本法則

  • 需求增加（$D$ 右移）：市價上漲、交易量增加（$P^* \uparrow$，$Q^* \uparrow$）[cite: 6]
  • 需求減少（$D$ 左移）：市價下跌、交易量減少（$P^* \downarrow$，$Q^* \downarrow$）[cite: 5, 6]
  • 供給增加（$S$ 右移）：市價下跌、交易量增加（$P^* \downarrow$，$Q^* \uparrow$）[cite: 5, 6]
  • 供給減少（$S$ 左移）：市價上漲、交易量減少（$P^* \uparrow$，$Q^* \downarrow$）[cite: 6]

(2) 供需雙重變動矩陣（大考必考重點）

同時變動型態 均衡價格（$P^*$）走向 均衡交易量（$Q^*$）走向 口訣與判斷心法
$D$ 增加 且 $S$ 增加 不一定（視移動幅度而定）[cite: 6] 必定增加（$Q^* \uparrow$）[cite: 6] 雙方都想擴大交易，數量必定增加[cite: 6]；價格一推一拉故不一定[cite: 6]。
$D$ 減少 且 $S$ 減少 不一定（視移動幅度而定） 必定減少（$Q^* \downarrow$） 雙方都收縮產能與消費，數量必定減少；價格一跌一張故不一定。
$D$ 增加 且 $S$ 減少 必定上漲（$P^* \uparrow$）[cite: 6] 不一定（視移動幅度而定）[cite: 6] 買方想多買、賣方產量少，價格必定暴漲[cite: 6]；數量互相抵銷故不一定[cite: 6]。
$D$ 減少 且 $S$ 增加 必定下跌（$P^* \downarrow$）[cite: 5] 不一定（視移動幅度而定）[cite: 5] 買方不買、賣方又大量上市，價格必定崩盤[cite: 5]；數量走向視幅度而定[cite: 5]。

考題給定變動幅度時的秒殺技巧

「幅度大的決定數量，方向相同的決定價格」[cite: 5]：

  • 範例：若供給增加幅度大於需求減少幅度[cite: 5]：
    價格：$S$ 增使價格跌、$D$ 減也使價格跌 $\implies$ $P^*$ 必定下跌[cite: 5]。
    數量：$S$ 增加（$Q \uparrow$）幅度較大，壓過 $D$ 減少（$Q \downarrow$）的幅度 $\implies$ $Q^*$ 必定增加[cite: 5]。

3. 政府價格管制政策（價格上限 vs 價格下限）

比較項目 價格上限（最高管制價格 / Price Ceiling） 價格下限（最低管制價格 / Price Floor）
主要保護對象 消費者（避免物價暴漲買不起民生物資）[cite: 6] 生產者 / 勞工（避免賤價傷農或薪資遭剝削）[cite: 5, 6]
有效管制的法規位置 必須設定在市場均衡價格之「下」（$P_c < P^*$）[cite: 6] 必須設定在市場均衡價格之「上」（$P_f > P^*$）[cite: 5, 6]
市場產生的失衡現象 超額需求（供不應求 / 缺貨）[cite: 5, 6]
依短邊原則，實際市場交易量縮小[cite: 5]		 超額供給（供過於求 / 滯銷）[cite: 5, 6]
在勞動市場上則表現為失業現象
衍生問題與配套措施 搶購排隊、黑市交易（黑市暴利）、定額配給[cite: 5, 6] 產品過剩積壓，需由政府保證收購或休耕補貼[cite: 3, 5]
大考常見代表實例 房租管制、水電油價凍漲、防疫口罩限價、奶粉凍漲[cite: 6] 最低工資（基本工資時薪制）、農產品保證收購價格[cite: 5, 6]

4. 考卷常見 3 大經典題型與解題步驟

題型一 聯立方程式求市場均衡

題目範例：$Q_d = 300 - 5P$，$Q_s = -80 + 5P$，求均衡價格 $P^*$ 與數量 $Q^*$[cite: 6]？

解題步驟：
  1. 令 $Q_d = Q_s$：$$300 - 5P = -80 + 5P \implies 10P = 380 \implies P^* = 38$$[cite: 6]
  2. 代回任一式求數量：$$Q^* = 300 - 5(38) = 300 - 190 = 110$$[cite: 6]
題型二 價格管制效果判斷

題目範例：承上題，若政府規定售價不得超過 $P = 30$，會產生何種現象[cite: 6]？

解題步驟：
  1. 判定管制型態：規定價格 $30$ 低於均衡價格 $38$，屬於具約束力的「價格上限」[cite: 6]。
  2. 代入需求：$Q_d = 300 - 5(30) = 150$[cite: 6]
  3. 代入供給：$Q_s = -80 + 5(30) = 70$[cite: 6]
  4. $Q_d (150) > Q_s (70)$，市場出現差額為 $80$ 的超額需求（供不應求）[cite: 6]。
題型三 相關財貨價格變動對均衡點之衝擊

題目範例：$A$ 財貨在需求上的替代品價格下跌，則 $A$ 財貨的均衡點如何變動[cite: 5]？

解題步驟：
  • 替代品價格下跌 $\implies$ 消費者改去買便宜的替代品，導致對 $A$ 的需求減少（$D$ 線左移）[cite: 5]。
  • 在供給線不變下，$D$ 左移導致均衡點沿著供給線往左下方滑動 $\implies$ $P^*$ 下跌、$Q^*$ 減少[cite: 5]。
